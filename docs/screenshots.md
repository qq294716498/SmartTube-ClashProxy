# README 界面素材

当前 README 使用两张仓库继承的 SmartTube 上游截图，并明确注明来源；`images/clash-center-preview.svg` 按本项目代理中心源码绘制，是示意图，节点和延迟为虚构演示数据，不是实机截图。

可补充以下本项目实机截图：

1. 首页正常加载，能看见顶部代理入口。
2. Clash 代理中心的连接与节点页，显示当前节点与延迟。
3. 订阅管理页或检测与日志页。

推荐 16:9 PNG，至少 1280 × 720；使用演示订阅名，隐藏订阅完整地址、token、节点凭据、账号头像/名称、局域网地址以及二维码/访问密钥。不要使用启动失败画面作为正常首页预览，不要把绘制图标成真实截图。

新增文件可放在 `docs/images/`，并同步更新 README 的图片路径、说明及来源。保留原始画面比例，压缩后确认电视字体仍可读。
