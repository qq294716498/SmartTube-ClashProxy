# 优兔喵视频

优兔喵视频是一款面向安卓电视和电视盒子的在线视频客户端，在大屏遥控器操作体验基础上集成了内置网络代理功能。

## 主要功能

- 适配电视遥控器的首页、搜索、播放和设置界面
- 首页右上角直接进入 Clash 代理中心
- 支持添加和管理多个订阅
- 支持手机扫码管理订阅和节点
- 支持切换订阅与节点
- 支持批量与单节点延迟测试、取消及按延迟排序
- 支持本地代理状态检测
- 支持导出初始化诊断日志
- 代理仅供本应用内部网络请求使用

## 手机扫码管理

在电视的 Clash 代理中心选择“手机扫码管理”，电视会显示二维码。手机与电视连接同一局域网后扫码，即可在手机浏览器中添加、编辑、删除订阅并选择节点。管理地址包含随机访问密钥，只在当前应用进程和局域网内有效。

## 使用方法

一、安装与设备架构匹配的安装包。多数新款安卓电视、电视盒子和手机使用六十四位版本。

二、打开首页，选择右上角 Clash 状态图标。

三、进入订阅管理，添加 HTTP 或 HTTPS 订阅地址并完成更新。

四、选择订阅、开启代理，再在节点列表中选择节点。

五、如果启动异常，可在“检测与日志”中检查连通性、执行核心自检并导出诊断日志。

## 构建说明

仓库提交后会自动执行代码检查和代理版安装包构建，并分别生成六十四位、三十二位与通用安装包。

构建流程会下载经过校验的内置代理核心，并核对文件摘要后再打包。

## 隐私与安全

- 订阅地址和配置仅保存在本机应用目录
- 诊断日志会隐藏完整订阅地址
- 本地视频代理仅监听本机回环地址
- 手机管理服务仅在用户主动打开后于局域网临时运行
- 手机管理地址使用随机访问密钥，重启应用后自动失效
- 不默认启用虚拟专用网络模式

## 开源说明

本项目基于开源电视客户端继续开发，并集成开源代理核心。使用、修改和分发时应遵守仓库许可文件及相关上游项目的开源许可。

## 本轮交互与路由改进

- 左侧固定保留代理开关与功能导航，右侧展示订阅和节点列表
- 测延迟结果直接显示在节点行中，切换成功后才更新使用中标记
- 代理开启但尚未就绪时不自动回退直连；关闭代理恢复直连
- 视频请求随当前代理状态路由，切换节点会清理旧连接，可能短暂重新缓冲
- 配置更新失败保留已有有效配置，手机与电视同时操作时防止订阅覆盖
- 连通检测不代表实际视频带宽；安装后的真机验收项目见仓库文档

HTTP 订阅使用明文传输；支持该协议不代表服务端链接一定有效。
